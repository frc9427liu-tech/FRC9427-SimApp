# 賽車模式設計書 08:道具設計 v2(MK8 Deluxe + Mario Kart World 合併)

> 日期 2026-10-24。起因:玩家實測回饋「油漬沒用;幾乎所有道具都會自動追蹤;往後丟也追(真遊戲不會);每個道具要研究它真正的功能、合併 MK8 與 World 的道具,沒用的要變有用」。
> 範圍:`RaceItems.cs`(表 / 使用 / 命中)、`ItemProjectiles.cs`(投射物)、`ItemEffects.cs`(持續效果 / 車身視覺)、`RaceHud.cs`(名稱 / 圖示)、`RaceItemsTest.cs`(I1~I41)。
> 資料來源說明:這份研究是**憑 MK8 Deluxe 與 Mario Kart World(2025)的已知行為整理,沒有逐條連網查證**(本次沒有用搜尋工具);標「?」的是 World 細節不確定的地方,不影響實作決策。本專案一律用**原創名稱 / 原創外觀**(程式生成幾何),不使用任天堂角色或貼圖。

## 2. 瞄準 / 鎖定規則(本次最重要的修正)

| 彈體 | 規則 | 實作 |
|---|---|---|
| 綠殼 `Bumper` / 三連彈 | 永遠直線,牆上反彈 3 次,**絕不追蹤** | `ItemProjectiles.MoveBumper` 只改方向於反彈;`Target` 恆為 null |
| 紅殼 `Homing` | 往前丟(發射方向與車頭夾角 <= 90 度)且前方有車才追;**往後 / 夾角 > 90 度:`NoHome`** → 走 `MoveBumper`(直線反彈)、`Target = null`、不計入 `IsTargeting`(不亮鎖定警告、不震動) | `FireHomingAt` 用 `Dot(dir, forward) < -0.001` 判斷;`IsTargeting` 排除 `NoHome` |
| 藍殼 | 永遠追第 1 名(`PickFirst`),不看方向 | 沒改,I36e 驗證 |
| 炸彈 / 假箱 / 香蕉皮 | 放置物,不追蹤 | — |
| 火球 / 迴力鏢 | 直線(迴力鏢回程對準主人,不是追敵人) | `IsTargeting` 不含 |

AI:`RaceItems.AiShouldUse` 的 `Homing` 分支——名次 > 1(前面有車)往前丟(拿到 1~3 s 後),且 25% 的 AI(`AiRoll < 0.25`)在後面 12 m 內有人貼著時改往後丟;第 1 名沒有目標,**等後面 25 m 內有人才往後丟**,否則拿著(20 s 後才丟掉)。

## 3. 香蕉皮(原 Oil,`ItemKind.Oil` 數值不變)

- **為什麼原本沒用**:油漬只有 1 s「抓地 x0.3 + 速度 x0.6」,AI 幾乎沒感覺,玩家也看不出被打中。
- **現在**:`Resolve(Oil)` = 受害車 `Stun(1.0 s)`(油門歸零、車身原地打轉 2 圈,`KartVisual` 畫旋轉)+ **掉 1 枚金幣**(`Stun(sec, coinLoss=1)`;其他暈眩仍掉 2)+ 之後 1.5 s 暈眩後無敵(不被連環踩)。第一台踩到的車消耗它;無敵 / 暈眩 / 羽毛跳躍中的車穿過去不消耗;護盾 / 喇叭規則同其他彈體。
- **外觀**:原創「香蕉皮」網格(`ItemProjectiles.PeelMesh`):中心 + 4 片往上翻捲的黃色細長果皮,雙面,附棕色小蒂;沒有任何角色 / 版權圖案。
- **丟法**:預設丟車後 2.6 m;手把下 / 瞄準可往前丟(最遠 8 m)或任意角度。
- **三連香蕉皮 `TripleBanana`(新,放在列舉末尾)**:持有時**車尾拖 3 片**(`ItemEffects.SyncTrail`,像三連彈的環繞作法);每按一次丟一片(間隔 0.3 s);拖著的時候,**從車後方來的殼(綠殼 / 紅殼 / 火球 / 迴力鏢)會先打掉一片**並消失(`RaceItems.TrailBlock`,每片擋一發,前方來的不擋,I38b/d)。全部丟完 / 被打光拖尾消失。
- AI:被鎖定或後面 18 m / 18 度內有車就丟;三連香蕉平常留著當護盾,30 s 後才丟。
- 顯示名:中「香蕉皮 / 三連香蕉皮」,英「Banana / Triple Banana」;賽前「只有香蕉皮」規則(`ItemRule = 3`)實際生效(Oil 55% / 三連 45%)。

## 4. 幽靈 Boo(新)
- 使用:從**名次在前面且手上有道具**的車中隨機挑一台,偷走其中一個(優先第 1 格;兩格都有各 50%;黃金加速進行中的不偷),放進自己空出來的格子,次數沿用對方剩下的;對方收到 `Dropped` 事件。
- 之後 **3 s**:無敵(所有道具穿過去、**閃電打不到**)+ 隱形(AI 車直接隱藏;玩家車保留可見並加淡藍光環,避免玩家看不見自己)。
- 沒人可偷 / 自己第 1 名:仍會隱形 3 s,不報錯(I39d)。機率表第 1 名 0%。AI:前面有人拿道具、被鎖定、或拿 12 s 就用。

## 5. 迴力鏢花 Boomerang(新)
- 3 次(間隔 0.4 s),速度 34 m/s:**去程直線 0.7 s(約 24 m,撞路邊就提早回頭)→ 回程直接對準主人飛回(轉頭那下減速再加速),進入 1.6 m 內被接住**。
- 穿過目標不消失:每一段(去程 / 回程)每台車最多打一次,所以最多打兩次(I40a:一台去程被打、另一台去程無敵穿過回程才被打)。命中 = 暈眩 0.9 s,規則同火球。
- 往後丟:去程朝後再飛回來(I40c)。AI:前方 24 m / 8 度或後方 18 m / 10 度有車就丟。
